# RNN 高级：LSTM、GRU 与时间序列预测

## 这节课解决什么问题？

day12 的普通 RNN 已经能把序列从前往后读，并用隐藏状态保存信息。但普通 RNN 有一个明显问题：序列变长后，早期信息要经过很多次状态更新，容易被覆盖；反向传播时梯度也容易消失或爆炸。

因此实际项目通常不会直接使用最简单的 `nn.RNN`，而会使用：

- **LSTM**：通过门控机制决定记住什么、忘掉什么；
- **GRU**：LSTM 的简化版，速度快、参数少；
- **双向 RNN**：同时利用过去和未来的上下文；
- **多层 RNN**：让低层学习简单变化，高层组合出更复杂的时序特征。

这类模型广泛用于销量/温度/流量预测、语音识别、文本分类、传感器异常检测、用户行为预测和设备状态监控。

## 一、先回顾普通 RNN 的局限

普通 RNN 每一步大致计算：

```text
h_t = tanh(W_xh x_t + W_hh h_(t-1) + b)
```

`h_t` 既要接收当前输入，又要保存历史信息。序列很长时，每一步都会用新状态重新混合旧状态，早期信息可能越来越弱。反向传播还会连续乘很多次权重：

- 乘到很多小于 1 的数：梯度越来越小，叫梯度消失；
- 乘到很多大于 1 的数：梯度越来越大，叫梯度爆炸。

这不是代码写错，而是普通 RNN 结构本身的限制。LSTM 和 GRU 的核心目标，就是提供一条更容易传递的记忆通道。

## 二、LSTM：用门控制记忆

### 1. LSTM 多了什么？

LSTM 同时维护两个状态：

- `h_t`：当前输出，短期工作记忆；
- `c_t`：细胞状态，长期记忆通道。

它使用三个门。门的输出是 0 到 1 之间的数，可以理解为软开关：

```text
遗忘门：旧记忆保留多少？
输入门：当前信息写入多少？
输出门：当前记忆输出多少？
```

门值不是人工指定的，而是神经网络根据 `x_t` 和 `h_(t-1)` 学出来的。

### 2. LSTM 的核心公式

下面公式不要求死记，重点是理解每个门的职责：

```text
f_t = sigmoid(W_f [h_(t-1), x_t] + b_f)   # 遗忘门
i_t = sigmoid(W_i [h_(t-1), x_t] + b_i)   # 输入门
g_t = tanh   (W_g [h_(t-1), x_t] + b_g)   # 候选记忆
c_t = f_t * c_(t-1) + i_t * g_t          # 更新长期记忆
o_t = sigmoid(W_o [h_(t-1), x_t] + b_o)   # 输出门
h_t = o_t * tanh(c_t)                    # 得到当前输出
```

`sigmoid` 输出接近 0 时表示“关掉”，接近 1 时表示“打开”。例如遗忘门为 0.9，表示保留大部分旧记忆；输入门为 0.1，表示当前候选信息只写入少量。

`c_t` 的更新包含“旧记忆乘遗忘门 + 新信息乘输入门”。这条加法通道比普通 RNN 反复整体覆盖更稳定，所以 LSTM 更容易学习长期依赖。

### 3. PyTorch 写法和形状

```python
self.lstm = nn.LSTM(
    input_size=3,    # 每个时间步 3 个特征
    hidden_size=32,
    num_layers=2,
    batch_first=True,
)
output, (hidden, cell) = self.lstm(x)
```

当 `x` 的形状是 `(N, T, 3)` 时：

```text
output: (N, T, 32)
hidden: (2, N, 32)   # num_layers=2
cell:   (2, N, 32)
```

序列分类通常使用 `output[:, -1, :]`；也可以使用 `hidden[-1]`，它表示最后一层的最终隐藏状态。两者在单向 LSTM 中表达的是同一时刻的信息。

## 三、GRU：更简单的门控 RNN

GRU 只保留一个隐藏状态，没有独立的 `cell`。它主要通过两个门工作：

```text
更新门：旧信息和新信息各保留多少？
重置门：计算新信息时参考多少旧状态？
```

```python
self.gru = nn.GRU(3, 32, num_layers=2, batch_first=True)
output, hidden = self.gru(x)
```

选择建议：

| 情况 | 建议 |
| --- | --- |
| 学习 RNN 原理、序列很短 | `nn.RNN` |
| 需要长期记忆、数据关系复杂 | `nn.LSTM` |
| 想要较快训练、参数少 | `nn.GRU` |
| 超长文本、需要并行训练 | 优先考虑 Transformer |

没有绝对最好的结构，最终应以验证集效果、训练速度和显存占用决定。

## 四、多层、双向和 Dropout

### 1. 多层 RNN

`num_layers=2` 表示上下叠两层 RNN。第一层先提取基础变化，第二层再组合第一层的输出，类似 CNN 中逐层提取从简单到复杂的特征。

```text
输入 -> 第1层 RNN -> 第2层 RNN -> 预测层
```

层数越多，表达能力越强，但也更难训练。小数据通常从 1 层开始。

### 2. 双向 RNN

`bidirectional=True` 会让一个 RNN 从左到右读，另一个从右到左读，然后拼接两个方向的结果：

```text
前向：x1 -> x2 -> x3 -> x4
后向：x1 <- x2 <- x3 <- x4
```

输出维度会变成 `hidden_size * 2`，所以分类层要写成：

```python
nn.Linear(hidden_size * 2, class_count)
```

双向模型适合文本标注、离线语音识别等“整段数据已经拿到”的任务。不适合实时预测未来，因为它会看到未来时间步。

### 3. RNN 的 Dropout

当 `num_layers > 1` 时，PyTorch 的 `dropout` 通常作用在层与层之间：

```python
nn.LSTM(3, 32, num_layers=2, dropout=0.2, batch_first=True)
```

它只在训练模式生效，预测前必须 `model.eval()`。单层 LSTM 设置 dropout 通常不会产生预期效果。

## 五、时间序列预测的关键：滑动窗口

真实时间序列通常是一长条数据，例如：

```text
第1天, 第2天, 第3天, ... 第1000天
```

RNN 训练时不能只给一条无限长序列，常用**滑动窗口**切成很多训练样本：

```text
输入 [第1~20天] -> 标签 第21天
输入 [第2~21天] -> 标签 第22天
输入 [第3~22天] -> 标签 第23天
```

窗口长度就是 `sequence_length`，决定模型一次能看到多长的历史。窗口太短可能看不到周期，太长会增加计算量并加重梯度问题。

### 数据划分不能泄漏未来

时间序列预测必须按时间顺序划分：前 70% 训练，中间 15% 验证，最后 15% 测试。不能像普通图片分类那样随机打乱后划分，否则训练阶段可能提前看到未来模式，测试结果会虚高。

### 预测连续数用什么损失？

```python
criterion = nn.MSELoss()  # 对大误差更敏感
# 或
criterion = nn.L1Loss()   # 对异常值更不敏感
```

分类任务才使用 `CrossEntropyLoss`。预测温度、销量等连续数时，最后一层通常不加 Softmax。

## 六、训练高级技巧

### 1. 梯度裁剪

LSTM/GRU 能缓解梯度问题，但仍可能梯度爆炸。反向传播后、更新参数前裁剪梯度：

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
```

`max_norm=1.0` 表示梯度整体太大时按比例缩小方向，不会改变正常的小梯度。

### 2. 归一化

温度、销量、传感器数值范围可能差异很大。常见做法是只用训练集计算均值和标准差：

```text
标准化值 = (原值 - 训练集均值) / 训练集标准差
```

验证集和测试集必须使用训练集的均值、标准差，不能各自重新计算，否则会泄漏未来信息。

### 3. 早停和保存最佳模型

训练损失继续下降不代表泛化能力继续变好。每轮在验证集上评估，连续若干轮没有改善就停止，并保存验证损失最低的权重。

## 八、常见错误

1. **双向 LSTM 后仍用 `Linear(hidden_size, ...)`**：双向输出是 `hidden_size * 2`。
2. **时间序列随机划分**：会把未来信息泄漏到训练集。
3. **回归任务使用 CrossEntropyLoss**：连续值预测通常用 MSE 或 L1。
4. **忘记反归一化**：模型输出仍是标准化数值，展示前要变回原单位。
5. **多步滚动预测误差累积**：后面的输入包含模型自己的预测，误差会逐步放大。
6. **只看训练集 loss**：必须看按时间隔离的验证集或测试集。

## 小结

1. 普通 RNN 的长期记忆能力有限，LSTM 用 `cell` 和三个门控制信息流，GRU 用更少的门实现类似目的。
2. 多层结构增加表达能力，双向结构利用完整上下文，但不能用于严格实时的未来预测。
3. 时间序列通常用滑动窗口构造样本，并按时间顺序划分数据，避免未来泄漏。
4. 连续值预测使用回归损失，训练时配合归一化、梯度裁剪和早停。
