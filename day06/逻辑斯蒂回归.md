# 逻辑斯蒂回归 Logistic Regression（二分类）

## 从线性回归到分类问题

在 day05 的线性回归中，我们使用下面的公式预测连续数值：

```text
y = wx + b
```

例如，根据房屋面积预测房价，输出可以是任意实数。

分类问题的目标不同。以“是否通过考试”为例，标签只有两种：

- `0`：未通过
- `1`：通过

我们希望模型输出一个 `0~1` 之间的概率，再根据概率判断类别。逻辑斯蒂回归就是在线性模型的输出后面接一个 Sigmoid 函数。

## 核心思想：Sigmoid 把线性输出变成概率

先计算线性输出：

```text
z = wx + b
```

再经过 Sigmoid 函数：

```text
sigma(z) = 1 / (1 + e^(-z))
```

得到预测概率：

```text
y_hat = sigma(wx + b)
```

Sigmoid 的输出范围始终在 `(0, 1)` 内：

- 输出接近 `0`：样本属于类别 `0` 的概率更大。
- 输出接近 `1`：样本属于类别 `1` 的概率更大。
- 通常以 `0.5` 作为分类阈值：概率大于等于 `0.5` 判为 `1`，否则判为 `0`。

> 名字中虽然有“回归”，逻辑斯蒂回归解决的却是分类问题。

## 为什么不用 MSELoss

线性回归预测连续值，常使用均方误差：

```text
MSE = (y_hat - y)^2
```

二分类更适合使用二元交叉熵损失（Binary Cross Entropy，BCE）：

```text
Loss = -[y * log(y_hat) + (1 - y) * log(1 - y_hat)]
```

PyTorch 中推荐使用：

```python
torch.nn.BCEWithLogitsLoss()
```

它将 `Sigmoid` 和 `BCELoss` 合并计算，数值更稳定。因此，模型的 `forward` 应直接返回线性层输出 `logits`，不要在模型中手动调用 Sigmoid。

## PyTorch 实现逻辑斯蒂回归：四步法

### 1. 准备数据

分类标签应使用 `0.0` 和 `1.0`，并且标签形状要与模型输出保持一致。

```python
x_data = torch.Tensor([[1.0], [2.0], [3.0], [4.0]])
y_data = torch.Tensor([[0.0], [0.0], [1.0], [1.0]])
```

这里每个样本只有一个特征，因此输入形状为 `(N, 1)`；`N` 表示样本数。

### 2. 构建模型

```python
class LogisticRegressionModel(torch.nn.Module):
    def __init__(self):
        super(LogisticRegressionModel, self).__init__()
        self.linear = torch.nn.Linear(1, 1)

    def forward(self, x):
        return self.linear(x)
```

`self.linear(x)` 的结果称为 `logits`，它可以是任意实数。训练时交给 `BCEWithLogitsLoss` 处理。

### 3. 定义损失函数和优化器

```python
model = LogisticRegressionModel()
criterion = torch.nn.BCEWithLogitsLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

### 4. 训练模型

训练过程仍然是：前向传播 -> 计算损失 -> 梯度清零 -> 反向传播 -> 更新参数。

```python
for epoch in range(1000):
    logits = model(x_data)
    loss = criterion(logits, y_data)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

## 预测时如何得到类别

训练完成后，先将 logits 转成概率，再根据阈值得到类别：

```python
with torch.no_grad():
    logits = model(x_data)
    probability = torch.sigmoid(logits)
    prediction = (probability >= 0.5).float()
```

`torch.no_grad()` 表示预测阶段不需要计算梯度，可以减少不必要的内存开销。

## 完整代码

```python
import torch


# 1. Prepare dataset
x_data = torch.Tensor([[1.0], [2.0], [3.0], [4.0]])
y_data = torch.Tensor([[0.0], [0.0], [1.0], [1.0]])


# 2. Design model using class
class LogisticRegressionModel(torch.nn.Module):
    def __init__(self):
        super(LogisticRegressionModel, self).__init__()
        self.linear = torch.nn.Linear(1, 1)

    def forward(self, x):
        return self.linear(x)


model = LogisticRegressionModel()

# 3. Construct loss and optimizer
criterion = torch.nn.BCEWithLogitsLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# 4. Training cycle forward, backward, update
for epoch in range(1000):
    logits = model(x_data)
    loss = criterion(logits, y_data)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if epoch % 100 == 0:
        print(f"epoch = {epoch}, loss = {loss.item():.4f}")

# Predict
with torch.no_grad():
    logits = model(x_data)
    probability = torch.sigmoid(logits)
    prediction = (probability >= 0.5).float()

    print("probability:")
    print(probability)
    print("prediction:")
    print(prediction)
```

训练后，前两个样本的预测概率应更接近 `0`，后两个样本的预测概率应更接近 `1`。

## 线性回归和逻辑斯蒂回归对比

| 对比项 | 线性回归 | 逻辑斯蒂回归 |
| --- | --- | --- |
| 解决问题 | 预测连续值 | 二分类 |
| 输出 | 任意实数 | 概率和类别 |
| 基本模型 | `Linear` | `Linear + Sigmoid` |
| 常用损失函数 | `MSELoss` | `BCEWithLogitsLoss` |
| 标签示例 | `12.5`、`38.0` | `0`、`1` |

## 小结

1. 逻辑斯蒂回归的本质是线性模型加 Sigmoid，用于输出二分类概率。
2. 使用 `BCEWithLogitsLoss` 时，模型输出 logits，不需要手动添加 Sigmoid。
3. 预测时使用 `torch.sigmoid()` 得到概率，再以 `0.5` 为阈值转换成类别。
4. 训练流程与线性回归相同，仍然遵循数据、模型、损失函数与优化器、训练循环这四步。
