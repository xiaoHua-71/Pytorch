# 梯度下降算法

## 为什么需要梯度下降

上一节的线性模型只有一个参数 `w`，可以靠「穷举 + 分治」在参数空间里搜索损失最小的点。但这种方法有根本缺陷：

- 参数一多（`w`、`b`、……），搜索空间**指数级增长**，穷举根本不现实；
- 分治隐含假设损失函数是「凸」的，对真实模型往往不成立；
- 本质是离散地试，效率极低。

所以需要一种能**连续地、自动地**把参数调到最优的方法，这就是梯度下降（Gradient Descent）。

## 目标：最小化损失

本例沿用 `day02/LossFunction.py` 的线性模型：

```python
y_pred = w * x + b
```

目标是让预测值 `y_pred` 尽量接近真实值 `y`，用**均方误差（MSE）**作为损失函数：

```python
loss = mean((y_pred - y) ** 2)
```

损失函数衡量当前模型有多差，训练的目标就是让 loss 尽量小。

## 梯度下降的思想

可以想象站在山坡上（loss 就是高度），要走到谷底（loss 最小）：

- **梯度**：损失函数在当前位置上升最快的方向，是一个向量，指向「最陡的上坡」；
- 沿着梯度的**反方向**走，就能最快地降低损失。

```text
参数 = 参数 - 学习率 * 梯度
```

### 导数、偏导与梯度

- 一元函数对参数的导数叫**导数**；
- 多元函数对每个参数分别求偏导，把这些偏导拼成一个向量，就叫**梯度**；
- 梯度向量的每个分量，就是损失函数对该参数的偏导。

本例需要更新两个参数 `w` 和 `b`：

```text
w = w - learning_rate * grad_w
b = b - learning_rate * grad_b
```

## 学习率 learning_rate

`learning_rate` 决定每次更新的步长：

- **过大**：可能一步跨过谷底，在两侧来回震荡，甚至发散到 loss 越来越大；
- **过小**：收敛很慢，需要大量迭代；
- **适中**：平滑地走向谷底。

## MSE 梯度的推导

对每个样本：

```text
error = y_pred - y = w * x + b - y
loss = mean(error ** 2)
```

利用链式法则，分别对 `w`、`b` 求偏导：

```text
grad_w = ∂loss/∂w = mean(2 * error * x)
grad_b = ∂loss/∂b = mean(2 * error)
```

对应代码就是 `LossFunction.py` 里的两行：

```python
grad_w = np.mean(2 * error * x_data)
grad_b = np.mean(2 * error)
```

## 把一步梯度下降封装成方法

下面的方法专门负责「一次梯度下降更新」，使训练循环更容易理解：

```python
def gradient_descent_step(x, y, w, b, learning_rate):
    """根据一批训练数据执行一次梯度下降，返回更新后的 w、b 和梯度。"""
    y_pred = w * x + b
    error = y_pred - y

    # 计算损失函数对 w、b 的梯度。
    grad_w = np.mean(2 * error * x)
    grad_b = np.mean(2 * error)

    # 沿梯度反方向更新参数，使损失逐步变小。
    w -= learning_rate * grad_w
    b -= learning_rate * grad_b
    return w, b, grad_w, grad_b
```

在训练循环中调用：

```python
for epoch in range(epochs):
    w, b, grad_w, grad_b = gradient_descent_step(
        x_data, y_data, w, b, learning_rate
    )
    current_loss = loss(x_data, y_data)
    losses.append(current_loss)
```

## 完整训练流程

```text
输入 x
  -> 前向计算：y_pred = w * x + b
  -> 计算误差：error = y_pred - y
  -> 计算梯度：grad_w、grad_b
  -> 沿反方向更新：w、b
  -> 重复多次，直到损失足够小
```

## 梯度下降的三种变体

根据「每次更新用多少样本计算梯度」来区分：

| 方法 | 每次更新用的数据 | 特点 |
| --- | --- | --- |
| 批量梯度下降（BGD） | 全部样本 | 方向稳定但计算慢，易陷于局部极小 |
| 随机梯度下降（SGD） | 1 个样本 | 快、噪声大，容易跳出局部极小，但震荡明显 |
| 小批量梯度下降（Mini-batch GD） | 一小批（如 32） | 实际最常用，兼顾稳定与速度 |

## 局部极小值与鞍点

- 若损失函数是**凸函数**，只有一个全局最小值，梯度下降一定能到达谷底；
- 但真实问题往往**非凸**，损失曲面有多个坑，梯度下降可能停在**局部极小值**，而非全局最小值；
- 还可能停在**鞍点**：此处梯度为 0，但既不是峰也不是谷，更新会停滞。

这也是后续引入动量（Momentum）、Adam 等优化器来改善收敛的原因。

## 运行结果

对于训练数据 `x = [1, 2, 3]`、`y = [2, 4, 6]`，训练收敛后参数接近：

```text
w ≈ 2
b ≈ 0
```

即模型学到了目标关系 `y = 2x`。观察训练过程中的 loss 曲线，可以看到 loss 逐渐下降并趋近于 0。
