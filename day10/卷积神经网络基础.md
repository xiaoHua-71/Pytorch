# 卷积神经网络基础 CNN

## 这节课解决什么问题

前面的全连接网络可以处理图片，但它通常需要先把图片“拉平”：例如一张 `28 x 28` 的灰度图片会变成长度为 `784` 的向量。

这样做有两个问题：

1. **图片的空间位置关系丢失了**：相邻像素原本很近，拉平后只是向量中的两个数字。
2. **参数数量太多**：图片尺寸变大后，第一层全连接层会产生大量参数，容易过拟合，也不容易训练。

卷积神经网络（Convolutional Neural Network，CNN）专门处理图片、视频帧等“有网格结构”的数据。它通过一个小窗口在图片上滑动，寻找边缘、纹理和局部形状，再逐层组合成更复杂的物体特征。

常见应用包括：

- 手写数字、猫狗、商品图片分类；
- 人脸和目标检测；
- 医学影像分析；
- 图片分割和图像增强。

## 图片在 PyTorch 中的形状

PyTorch 的二维卷积输入格式是：

```text
(N, C, H, W)
```

| 字母 | 含义 | 例子 |
| --- | --- | --- |
| `N` | batch 中图片数量 | 32 |
| `C` | 通道数 | 灰度图为 1，RGB 彩色图为 3 |
| `H` | 图片高度 | 28 |
| `W` | 图片宽度 | 28 |

例如：

```python
gray_images = torch.randn(32, 1, 28, 28)
color_images = torch.randn(32, 3, 64, 64)
```

注意，图片数据常见的格式是 `(H, W, C)`，而 PyTorch 卷积层需要 `(N, C, H, W)`。用 `permute` 可以调整维度：

```python
# 一张 HWC 格式的 RGB 图片
image_hwc = torch.randn(64, 64, 3)
image_nchw = image_hwc.permute(2, 0, 1).unsqueeze(0)
print(image_nchw.shape)  # (1, 3, 64, 64)
```

## 卷积层 `Conv2d` 是什么

可以把卷积核理解成一副小小的“筛子”。它在图片上从左到右、从上到下移动，每到一个位置，就把局部像素和卷积核权重相乘并相加，得到一个新的数字。

```python
layer = torch.nn.Conv2d(
    in_channels=1,
    out_channels=8,
    kernel_size=3,
    padding=1,
)
x = torch.randn(4, 1, 28, 28)
y = layer(x)
print(y.shape)  # (4, 8, 28, 28)
```

几个重要参数：

- `in_channels`：输入通道数，灰度图是 1，RGB 图是 3；
- `out_channels`：卷积核数量，也就是输出特征图数量；
- `kernel_size`：卷积核大小，常见是 `3` 或 `5`；
- `padding`：图片边缘补多少圈 0；
- `stride`：卷积核每次移动几格，默认是 1。

每个卷积核可能学会一种模式：第一个核检测竖直边缘，另一个核检测水平边缘，后面的卷积层则可以检测更复杂的角和形状。

## 输出尺寸怎么算

对于高度或宽度，卷积后的尺寸公式是：

```text
输出尺寸 = floor((输入尺寸 + 2*padding - kernel_size) / stride) + 1
```

例如输入是 `28`，`kernel_size=3`、`padding=1`、`stride=1`：

```text
(28 + 2*1 - 3) / 1 + 1 = 28
```

所以 `padding=1` 的 3×3 卷积通常不会改变高宽。若 `stride=2`，高宽大约缩小一半。

## 激活函数和池化层

### ReLU

卷积本身仍然是线性运算，需要激活函数增加非线性表达能力。最常用的是 ReLU：

```text
ReLU(x) = max(0, x)
```

```python
relu = torch.nn.ReLU()
```

### MaxPool2d

最大池化也用一个小窗口滑动，但只保留窗口内最大的值：

```python
pool = torch.nn.MaxPool2d(kernel_size=2)
x = torch.randn(4, 8, 28, 28)
y = pool(x)
print(y.shape)  # (4, 8, 14, 14)
```

池化的作用是缩小图片尺寸、减少计算量，并保留局部区域中最明显的特征。池化不会改变通道数。

## 一个典型的 CNN 结构

```text
图片 (N, 1, 16, 16)
  -> Conv2d(1, 8, 3, padding=1)  -> (N, 8, 16, 16)
  -> ReLU
  -> MaxPool2d(2)                 -> (N, 8, 8, 8)
  -> Conv2d(8, 16, 3, padding=1) -> (N, 16, 8, 8)
  -> ReLU
  -> MaxPool2d(2)                 -> (N, 16, 4, 4)
  -> Flatten                      -> (N, 256)
  -> Linear(256, 3)               -> (N, 3)
```

卷积层负责“看局部并提取特征”，全连接层负责“根据特征做最终分类”。`Flatten` 只改变形状，不会学习参数。

## 训练流程逐行理解

```python
model.train()                 # 训练模式
logits = model(images)        # 前向传播
loss = criterion(logits, labels)
optimizer.zero_grad()         # 清空上一次的梯度
loss.backward()               # 反向传播计算梯度
optimizer.step()              # 更新卷积核和全连接层参数
```

多分类时模型输出是 `(N, 类别数)` 的 logits，标签是 `(N,)` 的类别编号，损失函数仍然使用 `CrossEntropyLoss`。不要在模型最后手动添加 Softmax。

测试时：

```python
model.eval()
with torch.no_grad():
    logits = model(images)
    predictions = logits.argmax(dim=1)
```

## 常见错误

1. **把图片维度写成 `(N, H, W, C)`**：卷积层要的是 `(N, C, H, W)`。
2. **`in_channels` 写错**：灰度图用 1，RGB 图用 3，并且要和输入第二维一致。
3. **忘记 Flatten**：卷积输出是四维，传给 `Linear` 前通常需要 `torch.flatten(x, 1)`。
4. **Linear 输入数量算错**：先打印卷积部分输出形状，再计算 `通道 * 高 * 宽`，或使用 `nn.LazyLinear` 自动推断。
5. **标签类型错误**：`CrossEntropyLoss` 的标签使用 `torch.long`。
6. **训练和测试都用 `model.train()`**：含 Dropout 或 BatchNorm 时会造成评估结果不稳定。
7. **输入没有归一化**：图片像素通常应转换到 `[0, 1]`，必要时再做标准化。
8. **只看训练准确率**：一定要用没有参与参数更新的测试集检查泛化能力。

## 和全连接网络的对比

| 对比项 | 全连接网络 | 卷积神经网络 |
| --- | --- | --- |
| 输入处理 | 常先拉平成向量 | 保留图片的高、宽和通道 |
| 参数连接 | 每个输入连接到每个神经元 | 卷积核只连接局部区域 |
| 参数数量 | 图片变大时增长很快 | 通常更少，卷积核可复用 |
| 擅长任务 | 表格数据、简单向量 | 图片、视频帧、空间信号 |
| 主要模块 | `Linear` | `Conv2d`、池化、`Linear` |

## 小结

1. CNN 通过局部连接和卷积核复用，保留图片的空间结构并提取局部特征。
2. `Conv2d` 输入格式是 `(batch, channel, height, width)`。
3. 常见流程是“卷积 -> ReLU -> 池化”重复几次，再“Flatten -> Linear”分类。
4. 卷积层通常逐渐增加通道数，池化层逐渐缩小高和宽。
5. CNN 的训练流程和前面网络一样：前向传播、算损失、反向传播、更新参数。
