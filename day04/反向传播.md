## Back Propagation

### 什么是反向传播

从损失函数出发，沿计算图**从后往前**，用**链式法则**逐层求出每个参数（权重 w、偏置 b）对损失 L 的梯度（偏导数）的过程。

一句话：**前向传播算损失，反向传播算梯度。**

### 为什么需要它

- 单层模型（如 day03 的线性模型）梯度可以手动推导。
- 多层网络里，如果每一层都从头手推梯度，算到第 k 层要重复计算 k 层以上的所有偏导，代价指数级增长。
- 反向传播的聪明之处在于**逐层复用上游梯度**：输出层的梯度算出来后一路往上传，每层梯度只算一次，走一趟就能拿到所有参数的梯度。

### 核心：链式法则

设损失 L，中间变量 z，参数 w：

```
∂L/∂w = (∂L/∂z) · (∂z/∂w)
```

即：**上游梯度（∂L/∂z）× 局部梯度（∂z/∂w）**

### 前向传播 vs 反向传播

| 方向 | 做什么 | day03 对应 |
|------|--------|-----------|
| 前向传播 Forward | x → L，算出预测值和损失 | `forward()` |
| 反向传播 Backward | L → 参数，逐层传梯度 | 算出 `grad_w`、`grad_b` |

### 手推例子（呼应 GradientDescent.py）

模型：z = wx + b，损失：L = (z − y)²，单个样本。

前向：

```
z = w·x + b
L = (z − y)²
```

反向（链式法则，从 L 往 w、b 推）：

```
∂L/∂z = 2(z − y)          # 上游梯度
∂z/∂w = x                 # 局部梯度
∂z/∂b = 1

∂L/∂w = ∂L/∂z · ∂z/∂w = 2(z − y) · x
∂L/∂b = ∂L/∂z · ∂z/∂b = 2(z − y)
```

正好对应 GradientDescent.py 里的：

```python
error = y_pred - y          # error = z − y
grad_w = np.mean(2 * error * x)
grad_b = np.mean(2 * error)
```

### 与梯度下降的关系

| 环节 | 作用 |
|------|------|
| 前向传播 | 算预测值、算损失 |
| 反向传播 | 用链式法则求所有参数的梯度 |
| 梯度下降 | 拿梯度更新参数：w -= lr · grad_w |

反向传播只负责**求梯度**，更新参数是梯度下降做的。
