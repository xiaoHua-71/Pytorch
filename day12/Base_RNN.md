
# RNN 基础：让模型记住前面的信息

## 这节课解决什么问题？

前面的全连接网络和 CNN 通常把每个样本当成一次性输入；但很多数据是按顺序出现的：

- 一句话是“我喜欢这个电影”，词语顺序会影响意思；
- 今天的温度和前几天的温度有关；
- 语音是一串连续的声音；
- 股票、传感器、电量等数据都是按时间排列的。

这类数据叫**序列数据**。如果只看当前时刻，模型可能不知道前面发生过什么。RNN（Recurrent Neural Network，循环神经网络）每读入一个时间步，就把当前输入和上一步的“记忆”合并，得到新的记忆。

直观理解：RNN 像一个边读边记笔记的人。

```text
当前输入 x_t + 上一步记忆 h_(t-1) -> 新记忆 h_t
```

它被广泛用于文本分类、词性标注、机器翻译的早期模型、语音识别、时间序列预测、传感器异常检测等场景。

## 一、RNN 最重要的两个量

### 1. 输入 `x`

PyTorch 默认使用下面的形状：

```text
(sequence_length, batch_size, input_size)
```

例如 10 个时间步、每批 32 条样本、每个时间步 4 个特征：

```python
x.shape == (10, 32, 4)
```

如果创建 RNN 时写 `batch_first=True`，形状改为更直观的：

```text
(batch_size, sequence_length, input_size)
```

本笔记和 demo 都使用 `batch_first=True`，所以输入是 `(批次, 时间步, 特征数)`。

### 2. 隐藏状态 `h`

隐藏状态就是 RNN 的“短期记忆”。每一步都会更新它。PyTorch 的 `nn.RNN` 返回两个结果：

```python
output, hidden = rnn(x)
```

- `output`：每个时间步的隐藏状态，形状为 `(batch, sequence_length, hidden_size)`；
- `hidden`：最后一个时间步的隐藏状态，形状为 `(num_layers, batch, hidden_size)`。

做整段序列分类时，通常取最后一个时间步：

```python
last_output = output[:, -1, :]  # (batch, hidden_size)
logits = classifier(last_output)
```

### 3. RNN 每一步到底做了什么？

把一条序列拆开来看。假设序列有 3 个时间步：`x_1、x_2、x_3`。RNN 按顺序计算，而不是把所有值一次混在一起：

```text
h_0 = 初始记忆，通常全 0
h_1 = tanh(W_xh * x_1 + W_hh * h_0 + b)
h_2 = tanh(W_xh * x_2 + W_hh * h_1 + b)
h_3 = tanh(W_xh * x_3 + W_hh * h_2 + b)
```

最后的 `h_3` 同时包含当前输入 `x_3` 和之前逐步积累的信息，所以可以交给分类层或预测层。

公式中的含义：`W_xh` 把当前输入映射到隐藏空间，`W_hh` 把上一时刻的记忆映射到下一时刻，`b` 是偏置，`tanh` 提供非线性。

最关键的一点是：**所有时间步共用同一套 `W_xh、W_hh、b`**。不是每个时间步重新创建一个网络，因此序列变长时参数数量不会按时间步增加。这种“同一套参数反复使用”就是“循环”的来源。

### 4. 用生活例子理解隐藏状态

模型判断一句话情感时，会逐词更新记忆：读到“这家餐厅”形成主题，读到“菜”知道讨论的是食物，读到“好吃”留下正面信息。最后一个隐藏状态就像读完整句话后的总结。

如果改成“这家餐厅的菜不好吃”，后面的信息会更新之前的记忆。RNN 学习的不是原样保存所有历史，而是学习哪些历史信息值得保留。

### 5. 为什么不能只用当前输入？

```text
只看 x_t：预测结果 = f(x_t)
RNN：     预测结果 = f(x_t, h_(t-1))
```

只看当前词时，“银行”无法判断是银行机构还是河岸；结合前面的“去取钱”或“坐在河岸边”才有明确含义。`h_(t-1)` 就是把上下文带到当前时刻的通道。

## 二、把 RNN 展开：它其实是一条共享参数的深网络

代码里只写了一个 `nn.RNN`，计算时可以展开成多个相同的小模块：

```text
x_1 -> [RNN 单元] -> h_1 -> [RNN 单元] -> h_2 -> [RNN 单元] -> h_3
          ↑ 参数相同       ↑ 参数相同       ↑ 参数相同
```

这叫**按时间展开（unroll）**。展开后可以看成一条很深的网络，只不过“深度”由序列长度决定。

### 1. 时间反向传播 BPTT

普通神经网络通过 `loss.backward()` 反向传播；RNN 的梯度还要沿时间方向返回，所以叫 **Backpropagation Through Time，时间反向传播**。最后一步预测错了，误差会依次影响 `h_3、h_2、h_1`，模型才能学会更早的哪个输入导致错误。PyTorch 会自动完成这件事。

### 2. 梯度消失和梯度爆炸

反向传播经过很多时间步时，梯度会反复乘上权重和激活函数导数：

- 数值长期小于 1，梯度越来越小，早期信息几乎学不到，叫**梯度消失**；
- 数值长期大于 1，梯度越来越大，训练不稳定，叫**梯度爆炸**。

常见处理方法是使用 LSTM/GRU、梯度裁剪、截断超长序列、降低学习率，并观察 loss 是否出现 `nan`。

## 三、RNN 的记忆不是永久记忆

隐藏状态是固定长度向量，例如 `hidden_size=16` 只有 16 个数字，不可能原样保存整段文本，只能保存历史摘要。

- 太小：记忆容量不足，复杂关系表达不了；
- 太大：参数更多、速度更慢，也更容易过拟合；
- 普通 RNN 中，距离当前很远的信息可能逐步衰减。

`hidden_size` 不是“记住多少个时间步”，而是记忆向量的维度，需要通过验证集选择。

## 四、从输入到预测的完整链路

以“根据最近 20 天温度预测明天是否炎热”为例：

```text
20 天温度 -> (batch, 20, 1)
          -> RNN 依次读取 20 步
          -> 最后记忆 (batch, hidden_size)
          -> Linear 映射到 2 个类别
          -> logits (batch, 2)
          -> CrossEntropyLoss 与标签比较
```

这里的 `1` 表示每天一个特征。如果每天还有湿度、风速、气压，输入就是 `(batch, 20, 4)`，此时 `input_size=4`，但序列长度仍是 20。

## 五、PyTorch 中如何定义 RNN

```python
self.rnn = nn.RNN(
    input_size=1,      # 每个时间步有几个特征
    hidden_size=16,    # 记忆向量长度
    num_layers=1,      # RNN 层数
    batch_first=True,
    nonlinearity="tanh",
)
```

`input_size` 不是序列长度。例如一条长度为 20 的单变量温度序列，输入形状是 `(batch, 20, 1)`，因此 `input_size=1`。

如果不手动传入初始状态，PyTorch 默认使用全 0 的 `h_0`。也可以自己传入它，但形状必须是：

```text
(num_layers * num_directions, batch_size, hidden_size)
```

例如单向、两层 RNN 的初始状态是 `(2, batch, hidden_size)`；双向、两层则是 `(4, batch, hidden_size)`。

一个最小的序列分类模型：

```python
class SequenceClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.rnn = nn.RNN(1, 16, batch_first=True)
        self.fc = nn.Linear(16, 2)

    def forward(self, x):
        output, hidden = self.rnn(x)
        return self.fc(output[:, -1, :])
```

分类模型最后输出 `logits`，形状是 `(batch_size, 类别数)`。配合 `CrossEntropyLoss` 时，不要在模型最后手动加 `Softmax`。

`num_layers=2` 表示把两个 RNN 层上下叠起来：第一层的每个时间步输出，作为第二层对应时间步的输入。`bidirectional=True` 则会同时从前往后、从后往前读取序列，隐藏维度会变成 `hidden_size * 2`；它适合需要完整上下文的离线任务，但不适合严格的“只能使用过去预测未来”场景。

## 六、RNN 的训练流程

每个 batch 的标准流程如下：

```python
logits = model(inputs)                 # 前向传播
loss = criterion(logits, labels)       # 计算损失
optimizer.zero_grad()                  # 清空旧梯度
loss.backward()                        # 反向传播
optimizer.step()                       # 更新参数
```

训练前调用 `model.train()`，验证或预测前调用 `model.eval()`，并使用 `torch.no_grad()` 减少内存占用。

## 七、RNN、LSTM、GRU 怎么选？

### `nn.RNN`

结构最简单，适合入门和序列较短的任务。但序列很长时，容易出现梯度消失，较早的信息可能记不住。

### `nn.LSTM`

增加了输入门、遗忘门、输出门，能更好地保留长期信息。文本、长时间序列中很常见，但参数更多、速度稍慢。

```python
self.rnn = nn.LSTM(1, 32, batch_first=True)
output, (hidden, cell) = self.rnn(x)
```

LSTM 不只维护一个 `hidden`，还维护一条更适合长期传递的 `cell`（细胞状态）通道。三个门都输出 0 到 1 之间的数，可以把它们理解成软开关：

```text
遗忘门：旧记忆哪些要丢掉？
输入门：当前输入哪些要写入？
输出门：当前时刻哪些记忆要拿出来使用？
```

因此，当很早以前的信息仍然重要时，LSTM 可以让它沿着 `cell` 通道较稳定地传递；普通 RNN 则只能不断用新状态覆盖旧状态。门不是手工规则，而是模型从训练数据中学出来的数字。

### `nn.GRU`

可以看成 LSTM 的简化版，参数更少、速度更快，很多任务上效果接近 LSTM。没有单独的 `cell`：

```python
output, hidden = nn.GRU(1, 32, batch_first=True)(x)
```

GRU 把部分门合并，结构更简单：更新门决定保留多少旧信息，重置门决定当前计算参考多少旧信息。它没有独立的 `cell`，所以通常比 LSTM 更省显存、速度更快。

实际项目中通常先试 GRU；需要更强的长期记忆时再试 LSTM。超长文本现在也常用 Transformer，RNN 并不是所有序列任务的最佳选择。

## 八、常见输入和输出方式

| 任务 | 输入 | 常见输出 |
| --- | --- | --- |
| 整段序列分类 | `(N, T, F)` | 取最后一步，输出 `(N, C)` |
| 每一步都分类 | `(N, T, F)` | 使用全部 `output`，输出 `(N, T, C)` |
| 下一时刻预测 | 前面的时间步 | 最后一步预测一个数或向量 |

符号含义：`N` 是 batch 大小，`T` 是序列长度，`F` 是每步特征数，`C` 是类别数。

### 1. 整段序列分类

例如判断一条评论正面还是负面。读完整段后只需要一个结果，所以取最后一步的隐藏状态：

```text
(N, T, F) -> RNN -> (N, T, H) -> 取最后一步 -> (N, H) -> Linear -> (N, C)
```

### 2. 每一步都输出结果

例如给句子中的每个词标注词性，或者为视频的每一帧判断动作。每个时间步都接一个分类层：

```text
(N, T, F) -> RNN -> (N, T, H) -> Linear -> (N, T, C)
```

损失通常会把 `N` 和 `T` 展平后计算，或者使用带时间维度的实现。

### 3. 下一时刻预测

例如用前 20 天的销量预测第 21 天。输入是前 20 步，通常只使用最后一步的隐藏状态，最后一层输出一个连续数：

```python
self.fc = nn.Linear(hidden_size, 1)
prediction = self.fc(output[:, -1, :])
```

这时常用 `MSELoss` 或 `L1Loss`，而不是分类用的 `CrossEntropyLoss`。如果要连续预测多天，还要把预测结果继续作为下一步输入，这叫**滚动预测**；预测误差可能逐步累积，需要特别评估。

### 4. 编码器和解码器

机器翻译、语音转文字等任务常见“编码器-解码器”：编码器读取输入序列并压缩成状态，解码器根据状态一个词一个词地产生输出。早期的 Seq2Seq 模型主要使用 LSTM/GRU；长序列场景后来通常加入注意力机制或改用 Transformer。

## 九、常见错误

1. **维度顺序写错**：没设置 `batch_first=True` 时，输入必须是 `(T, N, F)`；设置后才是 `(N, T, F)`。
2. **把序列长度写成 `input_size`**：`input_size` 是每个时间步的特征数，不是时间步数量。
3. **标签类型错误**：分类标签要用 `torch.long`，形状通常是 `(N,)`。
4. **在 `CrossEntropyLoss` 前加 Softmax**：会影响损失计算，直接传 logits。
5. **忘记切换 `eval()`**：含 Dropout 或 BatchNorm 的模型验证时结果会不稳定。
6. **序列很长仍坚持用普通 RNN**：优先尝试 GRU/LSTM，并考虑截断序列或梯度裁剪。
7. **时间序列数据随机打乱造成泄漏**：预测未来时，验证集应按时间放在后面，不能把未来数据混入训练集。

## 小结

1. RNN 通过隐藏状态保存序列前面的信息。
2. 使用 `batch_first=True` 时，输入形状是 `(batch, time, feature)`。
3. 整段序列分类通常取 `output[:, -1, :]` 接全连接层。
4. 普通 RNN 适合入门和短序列，GRU/LSTM 更适合长期依赖。
5. 文本、语音、传感器和时间序列预测是 RNN 的典型应用场景。
