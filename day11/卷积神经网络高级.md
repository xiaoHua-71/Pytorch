# 卷积神经网络高级：让 CNN 更稳定、更强、更实用

## 这节课解决什么问题

day10 的 CNN 已经可以完成“输入图片 -> 卷积提取特征 -> 输出类别”的基本任务。但在真实项目中，我们很快会遇到这些问题：

- 网络变深后，训练变慢或不稳定；
- 训练集准确率很高，测试集准确率却很低，也就是过拟合；
- 数据量太少，模型很难学到通用特征；
- 图片尺寸变化后，手动计算全连接层输入很麻烦；
- 模型训练了很久，学习率不合适，损失下降很慢；
- 从零训练一个大型图片模型需要大量数据和时间。

本节的“高级”不是完全换一套知识，而是在基础 CNN 上增加解决这些问题的工具。

## 一、Batch Normalization：让训练更稳定

### 1. 它做了什么

一个 batch 中不同图片经过卷积后，数值范围可能差别很大。如果下一层接收到的数值忽大忽小，训练就会比较困难。

`BatchNorm2d` 会对每个通道的特征做标准化，再使用可学习的缩放和偏移：

```text
标准化结果 = (x - batch均值) / sqrt(batch方差 + 很小的数)
输出 = 可学习的缩放 * 标准化结果 + 可学习的偏移
```

不需要自己计算均值和方差，PyTorch 会自动完成。

```python
block = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),
    nn.BatchNorm2d(16),
    nn.ReLU(),
)
```

卷积输出有 16 个通道，所以 `BatchNorm2d(16)` 里的 16 必须和通道数一致。

### 2. 为什么要区分 `train()` 和 `eval()`

训练时 BatchNorm 使用当前 batch 的均值和方差；测试时使用训练过程中累计的均值和方差。因此必须写：

```python
model.train()  # 训练阶段
model.eval()   # 验证、测试、预测阶段
```

如果测试前忘记 `model.eval()`，结果可能不稳定。

## 二、Dropout：降低过拟合

过拟合可以直白地理解为：模型把训练题目背得太熟，却不会做新题。

Dropout 在训练时会随机把一部分神经元输出暂时变成 0，迫使网络不要过度依赖某几个神经元：

```python
self.dropout = nn.Dropout(p=0.5)
```

`p=0.5` 表示训练时大约随机丢弃一半输出。测试时 Dropout 会自动关闭，所以同一张图片的预测不会每次都随机变化，但前提是已经调用 `model.eval()`。

Dropout 常放在全连接分类头附近。卷积特征部分也可以使用 `nn.Dropout2d`，它会按通道随机丢弃特征图。

## 三、数据增强：让有限图片产生更多变化

真实图片可能发生平移、轻微旋转、亮度变化。训练时对图片做合理的随机变化，模型就不容易只记住某个固定位置。

常见增强包括：

```python
transforms.RandomHorizontalFlip(p=0.5)
transforms.RandomCrop(size=32, padding=4)
transforms.RandomRotation(degrees=10)
transforms.ColorJitter(brightness=0.2)
```

注意：增强必须符合任务常识。数字识别中随意水平翻转可能会改变数字含义；医学图像也不能随意改变方向。

通常只对训练集增强：

```python
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
])
test_transform = transforms.Compose([
    transforms.ToTensor(),
])
```

测试集应尽量代表真实使用时的原始数据，不能使用随机增强。

## 四、残差连接：让深层网络更容易训练

网络变深后，梯度可能在反向传播中越来越小，前面的层很难更新。这叫梯度消失。残差连接（Residual Connection）让输入可以绕过若干层，直接加到输出上：

```text
普通结构：       y = F(x)
残差结构：       y = F(x) + x
```

这条“捷径”也叫 shortcut。一个简单的残差块如下：

```python
class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.main = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(channels),
            nn.ReLU(),
            nn.Conv2d(channels, channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(channels),
        )
        self.relu = nn.ReLU()

    def forward(self, x):
        return self.relu(self.main(x) + x)
```

这里 `self.main(x)` 和 `x` 的形状必须完全相同，才能相加。如果通道数或图片尺寸不同，就需要使用一个 `1x1` 卷积调整 shortcut。

## 五、全局平均池化：减少手动计算

基础 CNN 常用 `Flatten` 后接 `Linear(通道 * 高 * 宽, 类别数)`。只要图片尺寸改变，Linear 的输入数量就可能要重写。

全局平均池化（Global Average Pooling，GAP）会对每个通道的整张特征图求平均：

```python
self.pool = nn.AdaptiveAvgPool2d((1, 1))
```

形状变化如下：

```text
(N, 32, 8, 8) -> (N, 32, 1, 1) -> (N, 32)
```

最后只需要 `Linear(32, 类别数)`。这样模型对输入高宽更灵活，也能减少参数和过拟合。

## 六、学习率调度和早停

学习率决定每次更新参数的步子大小：

- 太大：损失上下震荡，甚至变成 `nan`；
- 太小：训练非常慢，可能卡在不理想的位置。

可以让学习率随训练过程自动变化：

```python
scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer, step_size=10, gamma=0.5
)

for epoch in range(30):
    train_one_epoch()
    scheduler.step()  # 每个 epoch 结束后调用一次
```

这表示每 10 个 epoch 把学习率乘以 `0.5`。

早停（Early Stopping）则是在验证集损失连续多轮不再变好时停止训练，并保存验证集效果最好的模型，避免训练过久导致过拟合。

## 七、迁移学习：站在已有模型肩膀上

大型模型已经在 ImageNet 等大数据集上学会了边缘、纹理和形状等通用特征。自己的数据量较少时，可以直接使用这些特征，只重新训练最后的分类层：

```python
from torchvision.models import resnet18, ResNet18_Weights

model = resnet18(weights=ResNet18_Weights.DEFAULT)
for parameter in model.parameters():
    parameter.requires_grad = False

model.fc = nn.Linear(model.fc.in_features, class_count)
```

这叫特征提取。若数据量较多，也可以先冻结训练，再解冻最后几层进行微调（fine-tuning）。迁移学习通常比从零训练更省数据和时间。

## 常见错误

1. **BatchNorm 通道数写错**：`Conv2d` 输出多少通道，后面的 `BatchNorm2d` 就写多少。
2. **预测时忘记 `eval()`**：Dropout 和 BatchNorm 在测试阶段行为不同。
3. **测试集也做随机增强**：会使测试结果不稳定，不能真实反映模型效果。
4. **残差相加时形状不同**：`main(x)` 和 shortcut 必须形状一致，必要时用 `1x1` 卷积调整。
5. **scheduler 调用位置错误**：常见的 epoch 调度器通常每个 epoch 结束调用一次。
6. **迁移学习输入尺寸和归一化不匹配**：使用预训练模型时要按照对应权重的预处理方式准备图片。
7. **训练集准确率高就停止**：应以验证集指标选择模型，而不是只看训练集。

## 小结

1. BatchNorm 主要帮助训练稳定，Dropout 主要帮助减少过拟合。
2. 数据增强通过制造合理变化，提高模型对新图片的适应能力。
3. 残差连接让深层网络中的梯度更容易传播。
4. 全局平均池化减少参数，也避免手动计算卷积输出尺寸。
5. 学习率调度、早停和迁移学习是实际项目中非常常用的训练技巧。
