# 线性回归 Linear Regression（PyTorch 初体验）

| 天 | 内容 | 实现方式 |
|----|------|----------|
| day02 | 线性模型 + 穷举法 | numpy 手写 |
| day03 | 梯度下降 | numpy 手写 |
| day04 | 反向传播（链式法则） | numpy 手写 |

它们都是在**用 numpy 从零手写**：`forward`、`loss`、`backward`、`gradient_descent_step` 每个环节都要自己实现，梯度要用链式法则**手工推导**（见 `BackPropagation.py`）。

## 为什么引入 PyTorch

手写最大的痛点是**求梯度**：

- 模型一复杂，梯度推导工作量指数级上升；
- 每一层都要自己维护局部梯度、手动链式传播，极易出错。

PyTorch 的核心价值是**自动求导（autograd）**：

- 你只需要写 `forward`（前向计算）；
- `backward` 会自动沿计算图反向传播，把每个参数的梯度算好；
- `nn.Module` 帮你把参数、层组织起来，`optimizer` 帮你做参数更新。

于是同样的线性回归，代码结构从「四段手写」变成「四个对象 + 循环」。

## PyTorch 实现线性回归：四步法

### 1. 准备数据 DataSet

用 `torch.Tensor` 构造张量。注意要构造**列向量**：

```python
x_data = torch.Tensor([[1.0], [2.0], [3.0]])  # shape = (3, 1)
y_data = torch.Tensor([[2.0], [4.0], [6.0]])  # shape = (3, 1)
```

对比 numpy 版本的 `np.array([1.0, 2.0, 3.0])`（一维），PyTorch 里 `nn.Linear` 期望输入是 `(batch, in_features)` 形状，所以每个样本要单独占一行。

### 2. 设计模型 Model

定义一个类继承 `torch.nn.Module`：

```python
class LinearModel(torch.nn.Module):
    def __init__(self):
        super(LinearModel, self).__init__()
        self.linear = torch.nn.Linear(1, 1)   # in_features=1, out_features=1

    def forward(self, x):
        return self.linear(x)
```

关键点：

- **必须继承 `nn.Module`**：这样模型的参数（`weight`、`bias`）才会被框架管理、参与自动求导；
- **必须调用 `super().__init__()`**：Module 的内部状态需要初始化；
- **`nn.Linear(in, out)`**：一个全连接层，内部自动创建并初始化参数 `w`（shape 为 `(out, in)`）和 `b`；
- 只需要写 `forward`，**不需要写 `backward`**——自动求导会替你完成；
- 调用时写 `model(x)` 而不是 `model.forward(x)`：Module 的 `__call__` 内部会先做钩子等预处理，再调用你的 `forward`，所以 `model(x)` 是标准用法。

### 3. 构造损失函数与优化器 Loss & Optimizer

```python
criterion = torch.nn.MSELoss(reduction="sum")
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

- `MSELoss` 就是前几天的均方误差。`reduction="sum"` 表示把各样本误差**求和**（而不是取平均），对应课程原写法 `MSELoss(size_average=False)`——`size_average` 在新版 PyTorch 已弃用，等价写法就是 `reduction="sum"`；
- `torch.optim.SGD` 是随机梯度下降优化器，`model.parameters()` 告诉它**要优化哪些参数**（这里就是 `weight` 和 `bias`），`lr` 是学习率。

### 4. 训练循环 Training Cycle

```python
for epoch in range(1000):
    y_pred = model(x_data)             # 前向传播：算出预测值
    loss = criterion(y_pred, y_data)   # 计算损失

    optimizer.zero_grad()              # ① 梯度清零
    loss.backward()                    # ② 反向传播：自动求每个参数的梯度
    optimizer.step()                   # ③ 梯度下降：更新参数
```

三步缺一不可：

- **`zero_grad()` 为什么必须？** PyTorch 默认把梯度**累加**到 `.grad` 上，而不是覆盖。不每次清零，梯度会越叠越大，更新就错了；
- **`loss.backward()`** 做完昨天 `BackPropagation.py` 里手写的那套链式法则求导，`w.grad`、`b.grad` 就被算好了；
- **`optimizer.step()`** 等价于昨天手写的 `w -= lr * grad_w`、`b -= lr * grad_b`。

## 手写 vs PyTorch 对照

| 环节 | day04 手写（numpy） | day05（PyTorch） |
|------|--------------------|------------------|
| 参数 | `w = 0.0`, `b = 0.0` | `nn.Linear(1,1)` 自动初始化 |
| 前向传播 | `def forward(x, w, b)` | `def forward(x)` + `self.linear` |
| 求梯度 | 手写 `backward()`（链式法则） | `loss.backward()` 自动完成 |
| 更新参数 | `gradient_descent_step(...)` | `optimizer.step()` |
| 模型结构 | 无，纯函数 | `nn.Module` 子类 |

## 运行结果

对 `x = [1, 2, 3]`、`y = [2, 4, 6]`，训练 1000 轮：

```text
epoch=   1 loss=29.33604813

epoch= 100 loss=0.19871530

w = 1.9996
b = 0.0010
```

loss 随 epoch 单调下降，最终 `w ≈ 2`、`b ≈ 0`，模型学到了目标关系 `y = 2x`——与 day02–04 的结论一致。

## 小结

从本讲开始，写模型的范式固定为四件套：

```text
准备数据 → 设计模型（nn.Module）→ 选损失函数与优化器 → 训练循环
```

**`forward / loss / backward / step` 这套循环是后续所有深度学习任务的通用模板**，后面分类、卷积、循环网络等都建立在这个框架之上。区别只在于 `forward` 里的网络结构越来越复杂。
