# 多分类问题 Multiclass Classification

## 这节课解决什么问题

前面的逻辑斯蒂回归解决的是二分类问题，例如判断“通过/未通过”。但很多任务的一个样本可能属于三个或更多互斥类别：

- 根据花的特征判断它属于哪一种鸢尾花；
- 将手写数字图片识别为 `0~9` 中的一个数字；
- 根据商品信息判断它属于服装、食品或数码产品。

这类问题称为**多分类（multiclass classification）**。如果一共有 `C` 个类别，模型需要为每个样本输出 `C` 个分数，再选择分数最高的类别。

> 多分类假设每个样本只属于一个类别。若一张图片可以同时包含“汽车”和“行人”，那是多标签分类（multilabel classification），损失函数和标签格式都不同。

## 从二分类扩展到多分类

二分类模型通常只输出一个 logit：

```text
input -> Linear(D, 1) -> 1 个 logit
```

多分类模型输出每个类别对应的 logit：

```text
input -> Linear(D, C) -> C 个 logits
```

其中：

- `D` 是每个样本的特征数；
- `C` 是类别总数；
- logit 是模型给出的原始分数，可以是任意实数，并不是概率。

假设一个 batch 有 4 个样本，每个样本有 2 个特征，要分成 3 类：

```python
layer = torch.nn.Linear(in_features=2, out_features=3)
inputs = torch.randn(4, 2)
logits = layer(inputs)

print(logits.shape)  # torch.Size([4, 3])
```

输出的每一行对应一个样本，每一列对应一个类别：

```text
             类别 0  类别 1  类别 2
样本 0         1.2    -0.3     2.1
样本 1        -1.0     3.2     0.7
```

样本 0 的类别 2 分数最高，因此预测类别为 2。

## Softmax：把分数转换为概率

Softmax 会把一个样本的 `C` 个 logits 转换为 `C` 个概率：

```text
p_i = exp(z_i) / sum(exp(z_j))
```

转换后，每个概率都在 `(0, 1)` 内，并且同一样本的所有类别概率之和为 1：

```python
logits = torch.tensor([[1.2, -0.3, 2.1]])
probabilities = torch.softmax(logits, dim=1)

print(probabilities)
print(probabilities.sum(dim=1))  # tensor([1.])
```

`dim=1` 表示在每一行的类别维度上计算 Softmax。对于形状 `(N, C)` 的输出，通常不能写成 `dim=0`，否则会在不同样本之间计算概率。

Softmax 不会改变最大值所在的位置，所以取得预测类别时可以直接对 logits 使用 `argmax`：

```python
predicted_classes = logits.argmax(dim=1)
```

只有在需要展示概率或置信度时，才需要显式调用 `softmax`。

## 交叉熵损失 `CrossEntropyLoss`

多分类通常使用交叉熵损失。对于真实类别为 `y` 的样本，损失可以理解为：

```text
loss = -log(模型分配给真实类别 y 的概率)
```

模型给真实类别的概率越高，损失越小；如果模型非常自信地预测了错误类别，损失会很大。

PyTorch 推荐直接使用：

```python
criterion = torch.nn.CrossEntropyLoss()
loss = criterion(logits, targets)
```

`CrossEntropyLoss` 内部已经组合了 `LogSoftmax` 和 `NLLLoss`，计算方式更稳定。因此训练时有两条重要规则：

1. 模型最后一层直接输出 logits，**不要添加 `Softmax`**；
2. 标签保存类别编号，**不要手动转换成 one-hot**。

### 输入和标签格式

```python
logits = torch.tensor([
    [2.0, 0.5, -1.0],
    [0.1, 0.4, 1.8],
])                              # shape: (2, 3), dtype: float

targets = torch.tensor([0, 2])  # shape: (2,), dtype: long

criterion = torch.nn.CrossEntropyLoss()
loss = criterion(logits, targets)
```

| 数据 | 形状 | 数据类型 | 含义 |
| --- | --- | --- | --- |
| `logits` | `(N, C)` | 浮点型 | 每个样本对每个类别的原始分数 |
| `targets` | `(N,)` | `torch.long` | 每个样本的真实类别编号 |

类别编号必须在 `[0, C-1]` 范围内。例如 3 分类只能使用 `0、1、2`，不能使用 `1、2、3`。

## 完整代码 Demo：三类二维数据

下面构造三团二维数据，每一团代表一个类别。模型学习二维坐标到类别编号的映射，并使用 `DataLoader` 按小批量训练。

```python
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset


torch.manual_seed(0)


def make_dataset(samples_per_class=100):
    centers = torch.tensor([
        [-2.0, -1.5],
        [2.0, -1.0],
        [0.0, 2.0],
    ])

    features = []
    labels = []
    for class_index, center in enumerate(centers):
        class_features = center + 0.6 * torch.randn(samples_per_class, 2)
        class_labels = torch.full(
            (samples_per_class,), class_index, dtype=torch.long
        )
        features.append(class_features)
        labels.append(class_labels)

    return torch.cat(features), torch.cat(labels)


class MulticlassModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(2, 16),
            nn.ReLU(),
            nn.Linear(16, 3),
        )

    def forward(self, x):
        return self.network(x)  # 返回 logits，不添加 Softmax


x_data, y_data = make_dataset()
dataset = TensorDataset(x_data, y_data)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

model = MulticlassModel()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for epoch in range(100):
    model.train()
    total_loss = 0.0
    total_correct = 0

    for inputs, targets in train_loader:
        logits = model(inputs)              # (batch_size, 3)
        loss = criterion(logits, targets)   # targets: (batch_size,)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * inputs.shape[0]
        total_correct += (logits.argmax(dim=1) == targets).sum().item()

    if epoch % 10 == 0 or epoch == 99:
        average_loss = total_loss / len(dataset)
        accuracy = total_correct / len(dataset)
        print(
            f"epoch={epoch:3d}, "
            f"loss={average_loss:.4f}, accuracy={accuracy:.2%}"
        )

# 对三个新样本进行预测
model.eval()
test_inputs = torch.tensor([
    [-2.0, -1.0],
    [2.0, -1.5],
    [0.0, 2.5],
])

with torch.no_grad():
    test_logits = model(test_inputs)
    test_probabilities = torch.softmax(test_logits, dim=1)
    test_predictions = test_logits.argmax(dim=1)

print("probabilities:")
print(test_probabilities)
print("predicted classes:", test_predictions.tolist())
```

训练后准确率通常会接近 `100%`，三个测试样本通常分别预测为类别 `0、1、2`。这是因为示例数据分布较简单；训练集准确率高并不意味着真实任务也能获得相同效果。

## 训练、验证和预测

### 训练阶段

训练时需要梯度，并让模型处于训练模式：

```python
model.train()
for inputs, targets in train_loader:
    logits = model(inputs)
    loss = criterion(logits, targets)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

### 验证或测试阶段

验证时不更新参数，应关闭梯度计算：

```python
model.eval()
total_correct = 0

with torch.no_grad():
    for inputs, targets in valid_loader:
        logits = model(inputs)
        predictions = logits.argmax(dim=1)
        total_correct += (predictions == targets).sum().item()

accuracy = total_correct / len(valid_loader.dataset)
```

若模型中有 Dropout 或 BatchNorm，`model.train()` 和 `model.eval()` 尤其重要，因为它们会改变这些层的行为。

## 如何衡量分类效果

最直观的指标是准确率：

```text
accuracy = 预测正确的样本数 / 总样本数
```

但类别数量很不均衡时，准确率可能产生误导。例如 100 个样本中有 95 个属于类别 0，模型始终预测类别 0 也有 95% 的准确率。此时可以进一步观察：

- **混淆矩阵**：真实类别和预测类别的对应数量；
- **Precision**：预测为某类的样本中，有多少确实属于该类；
- **Recall**：真实属于某类的样本中，有多少被正确找出；
- **F1-score**：Precision 和 Recall 的综合指标。

简单的混淆矩阵可以这样统计：

```python
num_classes = 3
confusion_matrix = torch.zeros(num_classes, num_classes, dtype=torch.long)

for target, prediction in zip(targets, predictions):
    confusion_matrix[target, prediction] += 1
```

矩阵的行表示真实类别，列表示预测类别；对角线上的数字表示分类正确的样本。

## 与二分类的对比

| 对比项 | 二分类 | 多分类（互斥类别） |
| --- | --- | --- |
| 输出形状 | `(N, 1)` | `(N, C)` |
| 模型原始输出 | 1 个 logit | 每类 1 个 logit |
| 常用损失 | `BCEWithLogitsLoss` | `CrossEntropyLoss` |
| 标签形状 | `(N, 1)` | `(N,)` |
| 标签类型 | 通常为浮点型 | `torch.long` |
| 概率转换 | `sigmoid` | `softmax(dim=1)` |
| 得到类别 | 与阈值比较 | `argmax(dim=1)` |

## 常见错误

1. **在模型最后添加 Softmax**：`CrossEntropyLoss` 需要原始 logits，它会在内部完成相应计算。
2. **标签使用浮点型**：类别编号标签应为 `torch.long`，可使用 `targets.long()` 转换。
3. **标签形状写成 `(N, 1)`**：交叉熵的类别索引标签应为 `(N,)`，必要时可用 `targets.squeeze(1)`。
4. **输出节点数错误**：有 `C` 个类别，最后一层就应为 `Linear(..., C)`。
5. **类别编号从 1 开始**：PyTorch 的类别索引从 0 开始，范围是 `[0, C-1]`。
6. **`argmax` 维度错误**：对 `(N, C)` 使用 `argmax(dim=1)`，才能为每个样本选择类别。
7. **把多分类和多标签分类混淆**：互斥多分类使用 `CrossEntropyLoss`；多标签任务通常使用每类独立的 `BCEWithLogitsLoss`。
8. **只看训练集准确率**：应划分验证集或测试集，评估模型对未见数据的泛化能力。

## 进一步理解：为什么不用 one-hot 标签

类别 2 的 one-hot 表示是 `[0, 0, 1]`，但 `CrossEntropyLoss` 通常只需要整数 `2`。整数标签更节省空间，损失函数也可以直接取出真实类别对应的 log probability。

PyTorch 的 `CrossEntropyLoss` 也支持浮点概率目标，但那用于标签平滑、混合标签等特殊情况。初学多分类时应使用 `torch.long` 类型的类别编号，避免混淆两种接口。

## 小结

1. 多分类解决“从三个或更多互斥类别中选择一个”的问题。
2. 最后一层输出 `C` 个 logits，输出形状为 `(batch_size, class_count)`。
3. 训练时将原始 logits 和 `(N,)` 形状的 `long` 标签传给 `CrossEntropyLoss`。
4. 预测类别使用 `logits.argmax(dim=1)`；需要展示概率时使用 `softmax(dim=1)`。
5. 除训练损失外，还应在未参与训练的数据上检查准确率，并在类别不均衡时观察混淆矩阵等指标。
