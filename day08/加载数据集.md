# 加载数据集

## 为什么需要 `Dataset` 和 `DataLoader`

前面的例子直接把全部数据传给模型：

```python
prediction = model(x_data)
```

数据量较小时这样很方便，但真实数据集可能无法一次全部放入内存或显存。训练时通常把数据拆成多个小批次（mini-batch），每次只读取并训练其中一批。

PyTorch 将这件事拆成两个部分：

| 组件 | 作用 |
| --- | --- |
| `Dataset` | 保存数据，并定义如何根据索引取得一个样本 |
| `DataLoader` | 从 `Dataset` 中按批次取数据，并负责打乱、并行加载等工作 |

两者的关系可以理解为：`Dataset` 管理“有什么数据”，`DataLoader` 管理“怎样取数据”。

## 自定义 `Dataset`

自定义数据集需要继承 `torch.utils.data.Dataset`，并实现两个方法：

```python
from torch.utils.data import Dataset


class DiabetesDataset(Dataset):
    def __init__(self, x_data, y_data):
        self.x_data = x_data
        self.y_data = y_data

    def __len__(self):
        """返回数据集中的样本总数。"""
        return len(self.x_data)

    def __getitem__(self, index):
        """根据索引返回一个样本及其标签。"""
        return self.x_data[index], self.y_data[index]
```

- `__len__()` 让 `len(dataset)` 能够得到样本数。
- `__getitem__()` 让 `dataset[index]` 能够取得第 `index` 个样本。
- 单个样本通常返回 `(features, target)`，`DataLoader` 会把多个样本自动堆叠成一个 batch。

## 一个完整示例

下面使用内存中的多特征数据演示完整流程：

```python
import torch
from torch.utils.data import DataLoader, Dataset


class RegressionDataset(Dataset):
    def __init__(self):
        self.x_data = torch.tensor(
            [
                [1.0, 2.0, 3.0],
                [2.0, 1.0, 0.0],
                [0.0, 3.0, 1.0],
                [4.0, 2.0, 2.0],
                [3.0, 0.0, 4.0],
                [1.0, 4.0, 2.0],
                [5.0, 1.0, 3.0],
                [2.0, 3.0, 5.0],
            ],
            dtype=torch.float32,
        )
        self.y_data = (
            2 * self.x_data[:, 0:1]
            - 3 * self.x_data[:, 1:2]
            + 0.5 * self.x_data[:, 2:3]
            + 4
        )

    def __len__(self):
        return self.x_data.shape[0]

    def __getitem__(self, index):
        return self.x_data[index], self.y_data[index]


dataset = RegressionDataset()
train_loader = DataLoader(
    dataset=dataset,
    batch_size=2,
    shuffle=True,
)

print("样本数：", len(dataset))

for batch_index, (inputs, targets) in enumerate(train_loader):
    print(f"batch {batch_index}")
    print("inputs.shape =", inputs.shape)   # (2, 3)
    print("targets.shape =", targets.shape) # (2, 1)
```

原来 `__getitem__()` 返回的单个特征形状是 `(3,)`，单个标签形状是 `(1,)`。当 `batch_size=2` 时，`DataLoader` 会把它们分别组合成 `(2, 3)` 和 `(2, 1)`。

## 在训练循环中使用 `DataLoader`

使用小批量数据后，训练循环包含两层：外层遍历 epoch，内层遍历当前 epoch 的所有 batch。

```python
model = torch.nn.Linear(3, 1)
criterion = torch.nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for epoch in range(100):
    model.train()

    for inputs, targets in train_loader:
        predictions = model(inputs)
        loss = criterion(predictions, targets)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    if epoch % 10 == 0:
        print(f"epoch={epoch}, last_batch_loss={loss.item():.6f}")
```

每处理一个 batch，都要完成一次“前向传播 -> 计算损失 -> 梯度清零 -> 反向传播 -> 更新参数”。一个 epoch 表示完整遍历一次数据集，而不是只训练一个 batch。

如果需要统计整个 epoch 的平均损失，应考虑每个 batch 的实际样本数：

```python
total_loss = 0.0
total_samples = 0

for inputs, targets in train_loader:
    predictions = model(inputs)
    loss = criterion(predictions, targets)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    batch_samples = inputs.shape[0]
    total_loss += loss.item() * batch_samples
    total_samples += batch_samples

average_loss = total_loss / total_samples
```

这里乘以 `batch_samples`，是因为 `MSELoss` 默认返回当前 batch 的平均损失。最后再除以总样本数，才能得到整个 epoch 按样本计算的平均值。

## `DataLoader` 常用参数

```python
DataLoader(
    dataset,
    batch_size=32,
    shuffle=True,
    num_workers=0,
    drop_last=False,
)
```

| 参数 | 含义 |
| --- | --- |
| `dataset` | 要加载的数据集对象 |
| `batch_size` | 每个 batch 包含的样本数 |
| `shuffle` | 每个 epoch 开始时是否重新打乱数据 |
| `num_workers` | 使用多少个子进程加载数据，`0` 表示在主进程加载 |
| `drop_last` | 样本数不能整除 `batch_size` 时，是否丢弃最后一个不完整 batch |

例如数据集有 10 个样本，`batch_size=4`：

- `drop_last=False`：batch 大小依次为 `4、4、2`。
- `drop_last=True`：batch 大小依次为 `4、4`，最后 2 个样本被丢弃。

训练集通常设置 `shuffle=True`，验证集和测试集通常不需要打乱。Windows 环境中使用 `num_workers > 0` 时，应把程序入口放入：

```python
if __name__ == "__main__":
    main()
```

刚开始学习或遇到多进程加载问题时，可以先使用 `num_workers=0`。

## 从文件中读取数据

数据也可以在 `Dataset.__init__()` 中从 CSV 文件读取。例如：

```python
import numpy as np
import torch
from torch.utils.data import Dataset


class CsvDataset(Dataset):
    def __init__(self, file_path):
        data = np.loadtxt(file_path, delimiter=",", dtype=np.float32)
        self.x_data = torch.from_numpy(data[:, :-1])
        self.y_data = torch.from_numpy(data[:, -1:])

    def __len__(self):
        return self.x_data.shape[0]

    def __getitem__(self, index):
        return self.x_data[index], self.y_data[index]
```

`data[:, :-1]` 取除最后一列以外的所有列作为特征；`data[:, -1:]` 取最后一列作为标签，并保留二维形状 `(N, 1)`。若 CSV 包含表头、文本或缺失值，应使用 `pandas.read_csv()` 进行处理。

对于非常大的文件，不一定要在 `__init__()` 中一次读入全部数据。可以只保存文件路径和样本索引，再在 `__getitem__()` 中按需读取，这属于惰性加载。

## 训练集、验证集和测试集

数据集通常分为三部分：

| 数据集 | 用途 |
| --- | --- |
| 训练集 | 计算梯度并更新模型参数 |
| 验证集 | 调整超参数、选择模型，不更新参数 |
| 测试集 | 最后评估模型的泛化能力 |

可以使用 `random_split` 划分数据：

```python
from torch.utils.data import DataLoader, random_split

generator = torch.Generator().manual_seed(0)
train_size = int(0.8 * len(dataset))
valid_size = len(dataset) - train_size

train_dataset, valid_dataset = random_split(
    dataset,
    [train_size, valid_size],
    generator=generator,
)

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
valid_loader = DataLoader(valid_dataset, batch_size=32, shuffle=False)
```

验证时需要切换到评估模式并关闭梯度计算：

```python
model.eval()
with torch.no_grad():
    for inputs, targets in valid_loader:
        predictions = model(inputs)
        loss = criterion(predictions, targets)
```

## 常见错误

1. **只遍历一次 `DataLoader`**：遍历一次只代表一个 epoch，需要在外层增加 epoch 循环。
2. **忘记每个 batch 都清空梯度**：默认情况下梯度会累加，应在反向传播前调用 `optimizer.zero_grad()`。
3. **标签形状不一致**：模型输出为 `(batch_size, 1)` 时，标签也应保持相同形状。
4. **数据类型不正确**：`nn.Linear` 的输入通常使用 `torch.float32`；分类任务的类别标签配合 `CrossEntropyLoss` 时通常使用 `torch.long`。
5. **误以为 `len(loader)` 是样本数**：`len(dataset)` 是样本数，`len(loader)` 是每个 epoch 的 batch 数。
6. **最后一个 batch 大小不同**：这是正常现象；不要在代码中把 batch 大小写死，需要固定大小时再设置 `drop_last=True`。
7. **验证阶段仍在更新参数**：验证时不要调用 `backward()` 和 `optimizer.step()`，并使用 `model.eval()` 与 `torch.no_grad()`。

## 小结

1. `Dataset` 通过 `__len__()` 和 `__getitem__()` 定义数据集及单个样本的读取方式。
2. `DataLoader` 负责批量、打乱和并行加载数据。
3. 一个 epoch 是完整遍历一次数据集；一次参数更新通常对应一个 batch。
4. 训练数据通常打乱，验证和测试数据通常不打乱。
5. 使用数据加载器时，应持续检查输入、标签和模型输出的形状及数据类型。
