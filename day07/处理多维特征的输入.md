
# 处理多维特征的输入

## 为什么需要多维输入

前面的例子只有一个特征：

```text
y = wx + b
```

真实任务通常会同时使用多个特征。例如预测房价时，输入可以包含面积、房间数和房龄：

```text
y = w1*x1 + w2*x2 + w3*x3 + b
```

把一个样本的所有特征放在同一行，就得到二维输入张量：

```text
X.shape = (样本数, 特征数)
```

其中第一维是 batch，第二维是每个样本的特征数量。即使只有一个样本，也建议保留 batch 维度，使用 `(1, 特征数)` 而不是 `(特征数,)`。

## `nn.Linear` 与张量形状

```python
layer = torch.nn.Linear(in_features=3, out_features=1)
x = torch.randn(5, 3)       # 5 个样本，每个样本 3 个特征
y = layer(x)
print(y.shape)              # torch.Size([5, 1])
```

`Linear(3, 1)` 内部参数形状为：

```text
weight: (1, 3)
bias:   (1,)
output: (batch_size, 1)
```

计算过程可以写成 `Y = XW^T + b`。因此，输入最后一维必须等于 `in_features`。如果输入是 `(5, 4)`，却使用 `Linear(3, 1)`，就会出现矩阵维度不匹配错误。

## 一个多特征线性回归例子

下面用三个特征拟合关系 `y = 2*x1 - 3*x2 + 0.5*x3 + 4`：

```python
import torch

torch.manual_seed(0)

# 4 个样本，3 个特征，形状为 (N, D)
x_data = torch.tensor([
    [1.0, 2.0, 3.0],
    [2.0, 1.0, 0.0],
    [0.0, 3.0, 1.0],
    [4.0, 2.0, 2.0],
])
y_data = 2 * x_data[:, 0:1] - 3 * x_data[:, 1:2] \
          + 0.5 * x_data[:, 2:3] + 4


class LinearRegressionModel(torch.nn.Module):
    def __init__(self, feature_count):
        super().__init__()
        self.linear = torch.nn.Linear(feature_count, 1)

    def forward(self, x):
        return self.linear(x)


model = LinearRegressionModel(feature_count=3)
criterion = torch.nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for epoch in range(5000):
    prediction = model(x_data)       # (4, 1)
    loss = criterion(prediction, y_data)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if epoch % 1000 == 0:
        print(f"epoch={epoch}, loss={loss.item():.6f}")

print("weight =", model.linear.weight.detach())  # 接近 [[2, -3, 0.5]]
print("bias =", model.linear.bias.item())         # 接近 4

with torch.no_grad():
    one_sample = torch.tensor([[1.0, 2.0, 3.0]])   # 仍然是 (1, 3)
    print("prediction =", model(one_sample).item())
```

## 标签的形状要一致

`Linear(3, 1)` 的输出是 `(N, 1)`，回归标签也应使用 `(N, 1)`：

```python
y_ok = torch.tensor([[1.0], [2.0], [3.0]])  # (3, 1)
```

如果标签写成 `(N,)`，PyTorch 可能广播计算，虽然代码不一定立即报错，但会导致结果和预期不符。需要时可用 `y = y.reshape(-1, 1)` 显式整理形状。

## 从一维数据扩展到多维数据

| 项目 | 单特征 | 多特征 |
| --- | --- | --- |
| 输入形状 | `(N, 1)` | `(N, D)` |
| 线性层 | `Linear(1, 1)` | `Linear(D, 1)` |
| 每个样本 | 一个数 | 一个长度为 `D` 的向量 |
| 参数权重 | `w` | `D` 个权重 |

`D` 可以是任意正整数；只要数据的最后一维与 `in_features` 相同，同一个 `Linear` 层就能批量处理任意数量的样本。

## 常见错误

1. **把特征数写成样本数**：`Linear(N, 1)` 是错误的，`in_features` 应该是 `D`。
2. **漏掉 batch 维度**：单个样本应写成 `[[x1, x2, x3]]`，而不是 `[x1, x2, x3]`。
3. **标签维度不匹配**：让 `prediction.shape` 与 `target.shape` 保持一致。
4. **特征量纲差异过大**：训练前可对每一列做标准化，通常能让梯度下降更稳定。

## 小结

1. 多维特征输入的标准形状是 `(batch_size, feature_count)`。
2. `nn.Linear(feature_count, output_count)` 的 `in_features` 必须等于输入最后一维。
3. 多特征线性回归仍然遵循“准备数据 -> 定义模型 -> 损失与优化器 -> 训练循环”的流程。
4. 处理单个样本时保留 batch 维度，并检查输入、输出和标签的形状。
